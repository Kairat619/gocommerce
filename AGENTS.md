# GoCommerce — Agent Instructions

Go backend (Chi router, Inertia.js bridge) + React 19 frontend (Vite 6, Tailwind 3,
@inertiajs/react v2). PostgreSQL 16 via pgx/v5, queries generated by sqlc.

## Build / Lint / Test Commands

```bash
docker compose up -d                    # Start PostgreSQL (down to stop)
go run ./cmd/server/                     # Run server (port 8080)
go build -o server.exe ./cmd/server/     # Build binary
go vet ./...                             # Lint / static check
gofmt -w .                               # Format Go code
sqlc generate                            # Regenerate Go from sql/queries/*.sql

go test ./...                            # Run all Go tests
go test ./internal/service/...           # Test a single package
go test -run TestFunctionName ./...      # Run a single test function
go test -v -run TestName ./internal/service/  # Single verbose test in one package
```

Frontend (run from `frontend/`):
```bash
npm run dev        # Vite dev server (port 5173)
npm run build      # Production build → public/build/
npm run preview    # Preview production build
```

**No test files exist yet.** Use Go's stdlib `testing` package. Place tests alongside
source (`auth.go` → `auth_test.go`). No frontend test runner is configured.

## Architecture

```
cmd/server/main.go     # Entry point: router, middleware stack
internal/db/           # sqlc-generated code, conn, migrate, seed
internal/handler/      # HTTP handlers (home, auth, products, categories)
internal/middleware/   # Auth + Inertia shared-props middleware
internal/service/      # Business logic (auth)
internal/session/      # Cookie session store (gocommerce_session)
sql/schema/            # Numbered migrations (001_initial.sql...)
sql/queries/           # sqlc query defs (one file per table)
frontend/src/Pages/    # Inertia page components (mirror routes)
frontend/src/Components/ # Shared React components
```

- Routes in `cmd/server/main.go` (`go-chi/chi/v5`).
- Pages rendered via `renderer.Render(w, r, "Pages/Name", props)`.
- Auth user + flash available on every page via `DynamicSharedProps`.
- Session accessed via `session.FromContext(r.Context())`.
- Migrations run automatically on startup (idempotent, `internal/db/migrate.go`).

## Code Style — Go

**Imports**: three groups separated by blank lines — stdlib, third-party, internal
(`gocommerce/...`):
```go
import (
    "net/http"

    "github.com/go-chi/chi/v5"
    inertia "github.com/mayahiro/go-inertia"

    "gocommerce/internal/db"
)
```

**Naming**: packages lowercase single-word (`handler`, `service`); exported PascalCase,
unexported camelCase; struct fields PascalCase; sqlc emits snake_case JSON tags.

**Handlers** are closures returning `http.HandlerFunc`, built with a `New*Handler`
constructor that takes deps:
```go
func NewProductHandler(renderer *inertia.Renderer, queries *db.Queries) *ProductHandler {
    return &ProductHandler{renderer: renderer, queries: queries}
}

func (h *ProductHandler) Index() http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) { /* ... */ }
}
```

**Error handling**:
- Unexpected: `http.Error(w, err.Error(), http.StatusInternalServerError)`.
- Compare sentinels with `errors.Is()`; define as package-level `var`:
  `var ErrInvalidCredentials = errors.New("invalid email or password")`.
- User-facing errors: redirect with a flash message.
- All returned errors must be checked (Go convention).

**Validation**: validate in handler, build `inertia.ValidationErrors` map, return via
`inertia.WithValidationErrors(errs)` on redirect.

**Database**:
- Always pass `r.Context()` to query methods.
- Use sqlc types (`db.ListProductsParams`, etc.).
- `pgtype.UUID` (UUID), `pgtype.Text` (nullable string), `pgtype.Numeric` (decimal).
- Convert `pgtype` values to plain `map[string]any` before passing to Inertia.
- Serialize UUIDs as dashless hex: `fmt.Sprintf("%x", u.Bytes)`.

## Code Style — React / JSX

- Functional components only; one per file, filename matches component name.
- `export default function ComponentName({ prop1, prop2 })`.
- Imports: `import { Link, router, usePage } from "@inertiajs/react";` then local
  components (`import StoreLayout from "../Components/StoreLayout";`).
- Shared props via `usePage().props` (`auth`, `flash`, `errors`).
- Page titles via `<Head title="..." />`.
- Navigation: `<Link href="/path">` for GET; `router.post/put/delete("/path")` for
  mutations; preserve scroll with `{ preserveScroll: true }`.
- Styling: Tailwind utility classes, mobile-first (`sm:`, `md:`); indigo primary
  (`indigo-600`, `indigo-500`); common: `rounded-lg`, `px-4 py-2`, `text-sm font-medium`.

## Database Schema

Tables: `users`, `categories`, `products`, `orders`, `order_items`. UUID PKs
(uuid-ossp), `updated_at` triggers, `order_status` enum (pending, confirmed,
processing, shipped, delivered, cancelled).

- Add query: write SQL in `sql/queries/<table>.sql` → `sqlc generate` → use from
  `internal/db/`.
- Add migration: create `sql/schema/NNN_description.sql` (increment N); auto-applied.

## Conventions

- No comments unless explaining non-obvious business logic.
- No unused imports (Go won't compile).
- Session keys are snake_case strings (`"user_id"`, `"user_email"`).
- Flash message keys: `"success"` and `"error"`.

## Environment Variables

- `PORT` — server port (default `8080`).
- `SEED` — set `"false"` to skip DB seeding.
- DB connection hardcoded in `internal/db/conn.go` (user/pass/db `gocommerce`, port 5432).
